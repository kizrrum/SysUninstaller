# SysUninstaller

**Универсальный инструмент для принудительного удаления программ в Windows.**

Три метода деинсталляции, умная проверка обновлений, чистка реестра и полный контроль над процессом.

## Основные возможности

- **Три метода удаления:**  
  `Через службу` (подмена ImagePath), `Прямой запуск` (видимая консоль), `Через SYSTEM` (дублирование токена).
- **Автоматическое обновление** – программа сама проверяет новые версии на GitHub и может загрузить и установить их.
- **Мгновенная реакция на отсутствующий деинсталлятор** – если файл удаления не найден, сразу предлагается удалить запись реестра.
- **Удаление «висящих» записей реестра** в один клик.
- **Кнопка «⏹ Стоп»** для прерывания затянувшихся операций.
- **Временное отключение сети** для блокировки обратной связи.
- **Подробное цветное логирование** с отметками времени.
- **Информативные тултипы** на всех элементах интерфейса и встроенная справка (`?`).
- **Понятный диалог для пользователей без прав администратора** с объяснением, зачем нужны повышенные привилегии.
- **Автоопределение языка системы** – интерфейс и все сообщения автоматически отображаются на русском или английском.

## Требования

- Windows 7 / 8 / 10 / 11 (права администратора)
- .NET Framework 4.5.2 или новее

## Быстрый старт

1. Запустите программу (UAC запросится автоматически).
2. Выберите продукт из списка или введите его название вручную.
3. Выберите метод удаления (по умолчанию «Прямой запуск»).
4. При необходимости настройте таймауты, отключение сети или укажите свою команду.
5. Нажмите **«Запустить деинсталляцию»**.
6. Если после удаления запись осталась – дважды кликните по ней и выберите **«Удалить запись в реестре»**.
