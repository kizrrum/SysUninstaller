# ServiceSwapUninstaller

**Утилита для принудительной деинсталляции программ Windows через временную подмену службы.**

## Описание

Программа позволяет удалить любой продукт, зарегистрированный в разделе `Uninstall` реестра, путём временного изменения `ImagePath` указанной службы Windows на команду удаления (`msiexec /x {GUID}` или пользовательскую команду). Служба запускается, выполняет команду, затем оригинальный путь восстанавливается.

## Особенности

- Поиск GUID продукта по части названия.
- Работает с любой службой (например, `Spooler`, `wuauserv`, `upnphost`).
- Поддержка пользовательских команд (EXE, BAT, CMD).
- Настраиваемые таймауты и интервалы проверки.
- Автоматический запрос прав администратора при запуске.
- Подробное логирование с цветовой маркировкой.
- Обфускация кода (защита от реверс-инжиниринга).

## Требования

- Windows 7/8/10/11 (с правами администратора).
- .NET Framework 4.8 (или .NET Core/5+ при соответствующей сборке).

## Использование

1. Запустите программу от имени администратора (UAC запросится автоматически).
2. Введите:
   - **Имя продукта** — часть названия программы для поиска в реестре (например, `InfoWatch`).
   - **Имя службы** — служба, через которую будет выполняться команда (рекомендуется не критичная, например `Spooler`).
   - (опционально) **Команда для выполнения** — если хотите запустить не `msiexec`, а свой скрипт/EXE.
   - **Макс. время ожидания** и **Интервал проверки**.
3. Нажмите **Запустить деинсталляцию**.
4. Следите за процессом в логе. После завершения служба будет восстановлена.

## Сборка из исходников

1. Клонируйте репозиторий:  
   `git clone https://github.com/ваш-логин/ServiceSwapUninstaller.git`
2. Откройте `ServiceSwapUninstaller.sln` в Visual Studio 2022.
3. Выберите конфигурацию `Release` и соберите проект.
4. Готовый EXE лежит в `bin\Release\`.
