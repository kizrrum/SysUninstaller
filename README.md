# SysUninstaller

**Универсальный инструмент для принудительного удаления программ в Windows.**

Программа позволяет безопасно и гибко деинсталлировать любое приложение, зарегистрированное в разделе `Uninstall` реестра, используя один из трёх методов:

- **Через службу** – временная подмена `ImagePath` выбранной службы на команду удаления (запуск от `SYSTEM` в сессии 0).
- **Прямой запуск** – выполнение команды в интерактивном окне консоли от имени текущего администратора (рекомендуется для большинства программ).
- **Через SYSTEM** – дублирование токена `winlogon.exe` и запуск команды от `NT AUTHORITY\SYSTEM` без изменения служб.

Дополнительные возможности:
- Удаление «висящих» записей реестра (когда файлы уже отсутствуют, но запись осталась).
- Остановка длительных операций кнопкой «⏹ Стоп».
- Временное отключение сетевых адаптеров для предотвращения обратной связи с серверами.
- Подробное цветное логирование каждого шага.
- Удобный просмотр деталей программы (разработчик, версия, дата установки, команда удаления).

## ⚙️ Особенности

- **Поиск программ** по части названия с автоматической подстановкой GUID.
- **Три метода удаления** – выбирайте подходящий под конкретный случай.
- **Удаление записей реестра** в один клик – чистка системы от «мусорных» записей.
- **Настраиваемые таймауты** и интервалы проверки успешности удаления.
- **Автоматический запрос прав администратора** при запуске.
- **Защита от случайного завершения**: корректное восстановление службы и сети после отмены.
- **Работа с любыми типами установщиков** (MSI, InnoSetup, NSIS, InstallShield и др.).
- **Логирование** с отметками времени и цветовой индикацией.

## Требования

- Windows 7/8/10/11 (требуются права администратора).
- .NET Framework 4.5.2 или выше (рекомендуется 4.8).

## Использование

1. **Запустите программу от имени администратора** (UAC запросится автоматически).
2. Введите название продукта (часть имени) или выберите его из списка установленных программ справа.
3. Выберите метод удаления:
   - `Через службу` — укажите имя службы-посредника (например, `Spooler`).
   - `Прямой запуск` — откроется видимая консоль, в которой будет выполняться удаление.
   - `Через SYSTEM` — запуск от SYSTEM без изменения служб (требует `winlogon.exe`).
4. При необходимости укажите **пользовательскую команду** (вместо автоматической из реестра).
5. Настройте **максимальное время ожидания** и **интервал проверки**.
6. Отметьте «Отключить сеть», если нужно предотвратить обмен данными с серверами.
7. Нажмите **«Запустить деинсталляцию»**.  
   В любой момент можно нажать **«⏹ Стоп»**, чтобы прервать ожидание и восстановить среду.
8. Если после удаления запись осталась в списке, дважды кликните по ней и нажмите **«Удалить запись в реестре»**.

## Сборка из исходников

1. Клонируйте репозиторий:  
   `git clone https://github.com/ваш-логин/SysUninstaller.git`
2. Откройте `SysUninstaller.sln` в Visual Studio (2019 или новее).
3. Соберите проект в конфигурации `Release`.
4. Исполняемый файл будет находиться в `bin\Release\`.
